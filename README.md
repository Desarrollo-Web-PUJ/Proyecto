# Sistema de gestion multiempresa
Con este proyecto organizado por Vamos a desarrollar a través del sistema crud Un sistema para la gestión de múltiples empresas Que les permita tener una interfaz común para el manejo de estas mismas, con este proyecto buscamos brindar Procesos de mayor seguridad , confiabilidad Y optimización A cualquier tipo de empresa que sea sumarse a este plan 

Descripción

Este proyecto, utilizando tecnologías Springboot,Html,js,Thymeleaf etc, va a hacerse a travez del metodo de desarrollo CRUD (create, replace, update, delete), Con el cual cualquier empresa que decida sumarse A nuestra misión será capaz Gestionar como se crea edita consulta y elimina, Valga la redundancia Dicha empresa, además de esto vamos a ofrecer un historial de todos los cambios Tanto internos Coma ya sea personal o gestión interna ¿Cómo externos ya sea la triazabilidad Oh funciones del proyecto, Ofreciendo un sistema Novedoso, consistente Y de fácil uso y manejo
Desarrollo
A través del desarrollo de este curso Y con ayuda de github Vamos a ir generando diferentes historias de usuario coma así como reportes del proyecto Dando un historial y una medida de ayuda Para la creación del mismo Coma durante el cual también se harán pruebas de ejemplo antes de ser lanzado realmente

Características

Multiempresa (multi-tenant): cada organización tiene su propio espacio aislado; los procesos pertenecen a la empresa, no a usuarios individuales, Esto asegura que a pesar de todas estas estar en una misma interfaz Coma cada empresa tenga su propio espacio personal Sin tener la reglación alguna con las otras Más allá de la implementación del sistema A realizar

Autenticación segura con control de acceso por empresa y roles (administrador, editor, solo lectura), Esto se hace con el fin de que cada empresa pueda delegar Criterio propio como se debe manejar está internamente Coma ya que nosotros como creadores no buscamos tener Ninguna intervención directa en cómo la empresa gestion Sus propios procesos internos

CRUD de procesos organizacionales: nombre, descripción, categoría y estado (borrador / publicado).

Historial y trazabilidad de cada cambio realizado sobre un proceso.

Búsquedas y filtros avanzados sobre procesos, Con esto buscaremos implementar un sistema de filtrado para que la empresa pueda buscar con más facilidad el proceso , empleado , trabajo O función Que se ha de realizar

Eliminación lógica (estado inactivo) para no perder información histórica, Claramente Respetando los derechos de privacidad de cada usuario así como de la propia empresa

Editor visual de procesos mediante actividades, arcos y gateways (exclusivos, paralelos e inclusivos).

Roles funcionales asociados a actividades, con validación de uso antes de eliminarlos.
